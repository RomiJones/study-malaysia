# 任务看板

任务看板是中文文档化任务管理，不是业务数据库。

- TASK-001：静态页面功能提取与升级 PRD 生成（高，产品）
- TASK-002：静态页面视觉规范与样式还原基线提取（高，前端，已完成）
- TASK-003：旧系统功能差距分析（高，架构）
- TASK-004：院校与专业数据模型及 API 升级（高，后端）
- TASK-005：管理端字段维护与内容管理升级（中，管理端，待评审）
- TASK-006：用户端页面结构与静态样式 1:1 还原（高，前端）
- TASK-007：搜索筛选、专业详情与对比功能升级（高，前端，待评审）
- TASK-008：收藏、规划工具、用户画像与申请任务升级（中，前端）
- TASK-009：端到端验证、视觉对比和验收报告（中，测试，待评审 / 验收有风险）
