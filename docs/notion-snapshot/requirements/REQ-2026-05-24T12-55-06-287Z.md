## TASK-051 边界补充

### 目标和用户价值

本需求第一阶段聚焦马来大学（Universiti Malaya / UM）数据导入边界：从 `D:\mydev\StudyMY_UM_v58_na_display_tidy.html` 中提取 UM 院校、专业、费用、学制、入学要求、语言要求、申请材料、开学时间、校园设施、申请信息、官方来源和审计说明，并在后续任务中进入 StudyMY 后端对应数据库和 API 数据模型。这样用户端和管理端可以共享同一套可维护、可校验、可追溯的数据。

### 功能范围

- 覆盖 UM 院校主档、本科专业、硕士专业、博士专业、校园设施、申请信息和官方来源。
- 保留费用、语言要求、学术要求、申请材料、公开展示状态、核验时间、来源 URL 和审计备注等关键字段。
- 后续实现必须先生成 dry-run 报告，说明提取数量、字段缺失、重复项、公开展示状态、来源缺失和风险项。
- 公开用户端主列表只能展示满足公开展示条件的数据；隐藏未核验、不开放国际学生或来源不足的数据应保留在管理端核验范围内。

### 非目标

- TASK-051 不修改业务代码、不导入数据库、不创建迁移、不生成 seed 数据。
- 除非后续人工确认，本需求不扩展到静态 HTML 中其他院校。
- 本需求不重新设计 UI，不覆盖此前任务的实现或 Review 问题。
- Notion、Markdown 快照、静态 HTML 和 `task.json` 都不是业务数据库。
