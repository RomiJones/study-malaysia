# 任务：USM 硕士官方数据商用发布

- **任务标识**: TASK-USM-MASTER-PUBLISH-20260614
- **状态**: 已完成
- **授权来源**: 用户于 2026-06-14 明确要求完成 USM 硕士数据入库并进行全栈验收

## 目标

将已审计的 USM 硕士官方目录 274 条记录转换为 StudyMY 四语商用数据并受控发布，保证数据库、公开 API 和用户端数量一致，同时只向国际学生公开已确认可申请的项目。

## 约束

- 仅处理 `universityCode=USM`、`level=master`。
- 目录口径为 274 个唯一公开硕士详情入口，不冒充需要登录的 OnlineIPS 最终申请选项数。
- 学制主展示统一使用年；原始学期、月份和年限文本保留在审计字段。
- 官方已公布费用按其原始币种展示；研究型每学期费率仅按官方全日制学制计算总学费区间，不做汇率换算。
- 没有唯一适用公开总学费的记录明确显示“官方未公布”，不得套用其它项目费率。
- 仅限马来西亚申请人或公开页面未确认国际生资格的项目保留在审计目录，但不进入国际学生普通专业列表。
- 旧 USM 硕士公开记录归档，避免重复展示；本科、博士和其它院校数据不受影响。
- 写库前生成 USM 当前数据库备份，写入与数量校验在同一事务中完成。

## 验收标准

- USM 公开本科保持 63 条，硕士官方目录为 274 条，其中国际生可公开硕士为 270 条。
- USM 院校公开专业总数为 333 条；另有 4 条保留在审计目录。
- 274 条硕士均具备四语名称、学院、简介、申请材料、官方来源和审计信息。
- 所有可换算学期和月份的学制均以年展示，例如 6 学期显示为 3 年。
- 数据库、API 和前端的硕士数量、项目层级、学制和费用口径一致。
- 自动化测试、API 构建和真实浏览器验收通过后才提交。
