## 项目目标

面向 StudyMY 计划覆盖的 119 所马来西亚院校，建立以官方来源、明确学年、完整证据、四语展示和商用发布门禁为核心的数据采集流程。Skill 不仅负责抓取，还负责来源裁决、字段归一化、冲突保留、受控入库、API 校验和前端上线验收。

## 固化原则

- 每次仅处理一所院校、一个学历层级、一个申请人范围和一个学年。
- 完整性结论必须绑定明确范围，不使用无边界的“全部最新数据”表述。
- 区分独立招生项目与专业方向、课程模块、培养路径和职业方向。
- 官方公布金额、币种、费用口径和学年是主事实，换算金额不得冒充官方学费。
- 官方未公布的课程、认证、截止日期或中国学生专项路径必须明确标注未公布，不作推断。
- 采集完成不等于可上线；数据库、API、四语页面、测试、构建和浏览器验收均为发布门禁。
- 新官网变化先作为增量差异分类，不直接覆盖已确认学年的规范目录。

## 第二轮复盘

USM 硕士阶段暴露出四个可以前移的问题：

1. 目录入口数、规范项目数和国际生公开数没有在最前面同时锁定，导致后期才调整 274、270 和 4 条例外的展示口径。
2. 国际生资格与学费主展示在发布阶段才统一，造成“每学期费率”和“总学费”之间出现返工。
3. 采集、候选构建、发布和 UI 验收虽有脚本，但缺少一个能证明整轮交付完整性的统一机器门禁。
4. 已解决的同名、方向、track 和费用映射例外仍偏向人工过程，应固化为映射规则和回归测试。
