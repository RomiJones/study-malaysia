# 任务：前端中英文翻译和页面文案统一修复

- **任务编号**: TASK-030
- **任务标题**: 前端中英文翻译和页面文案统一修复
- **状态**: 已阻塞
- **优先级**: 高
- **任务类型**: 前端
- **负责人**: Codex
- **关联需求**: 产品需求文档

- **实现说明**: 本任务允许修改业务代码和测试代码。修复用户端翻译和页面文案问题，重点检查中文/英文混用、硬编码文案、缺失 i18n key、按钮文案、筛选标签、专业字段标签、空状态、错误提示、登录弹窗、收藏/对比/规划相关文案。页面必须严格遵循当前多语言设定，`zh-CN`、`zh-TW`、`en`、`ms` 四种语言切换后不得出现非当前语言的界面文案；官方学校英文名、专业官方英文名、QS、IELTS、TOEFL、GPA、RM、CNY 等专有名词可以保留。不得大改整体样式，只统一文案、翻译和局部排版。
- **测试计划**: 运行 `npm run build`；检查 i18n key；浏览器验证 `zh-CN`、`zh-TW`、`en`、`ms` 四种语言关键页面；运行截图对比脚本。
- **验证结果**: Codex 已完成实现并返回完成状态。
- **阻塞说明**:Review 未通过：本轮 Review 重新检查了 TASK-030 的多语言实现。此前英文分类泄漏、繁体动态简体残留、登录错误透出英文后端错误这三类问题在静态审计和关键页面抽查中未复现；但多语言视觉回归脚本和真实 API 页面仍发现专业详情弹窗的官方学制详情直接展示英文运行时文案，因此结论为需要修复。

## 验收标准
- 用户端主要页面没有明显中英文/马来文/繁体中文混杂、缺失翻译 key 或硬编码残留，除官方英文名称、学校简称和通用考试/币种/排名缩写外。
- 首页、列表、详情页、专业弹窗、收藏、对比、规划、登录弹窗的按钮、标题、提示和字段标签文案统一。
- 简体中文、繁体中文、英文、马来文文案都符合专业留学产品表达，不使用生硬直译；英文文案不影响原始官方名称展示。
- 空状态、错误状态、加载状态和权限提示文案完整。
- 四种语言切换后，关键页面文案、按钮、字段标签、空状态和弹窗均保持当前语言；`npm run build` 和浏览器抽查通过。
