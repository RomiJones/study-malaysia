- **任务标识**: TASK-USM-UG-PUBLISH-20260613
- **状态**: 已完成
- **优先级**: 最高
- **任务类型**: 官方数据治理与发布
- **授权来源**: 用户于 2026-06-13 明确要求一次完成 USM 本科权威、商用、可直接上线的数据
- **关联需求**: 院校、专业、费用、学制、要求、申请材料、开学时间、职业方向、四语言和官方来源展示
- **关联技术方案**: TypeORM/MySQL 数据层、公开展示门禁、四语言业务数据和官方来源审计

## 任务目标

以 USM 官方《Prospectus for First Degree Academic Session 2025/2026》为规范主目录，将国际本科 63 个招生项目完整归一化，解决既有 CSV 的重复行、错误代码、旧专业拆分和费用冲突，并受控发布到 StudyMY 本地数据库。

## 权威来源顺序

1. 2025/2026 First Degree Prospectus：专业代码、名称、院系、学制、入学要求、语言要求、面试、职业方向和费用。
2. 2025/2026 Summary of Programme：63 个项目和学期开放范围交叉核对。
3. 国际本科费用 PDF：按代码交叉核对每学期费用。
4. 当前国际本科 CSV：仅用于检查目录变化和详情页链接，不作为规范专业主表。
5. USM 官方专业详情页：用于补充课程、职业和页面级证据。

## 实施边界

- 仅处理 `universityCode=USM`、`level=bachelor`。
- 正式集合固定为官方 Prospectus 的 63 个项目，包含 4 个 offshore 项目。
- 91 行 CSV 审核记录继续保留为历史证据，但不得进入公开目录。
- 旧 USM 本科公开记录必须归档，避免与 63 项规范集合重复展示。
- 不修改 USM 硕士、博士、其它院校或用户收藏、规划、申请数据。
- 美元金额必须保留两位小数，不得取整或仅保存在展示字符串中。
- 官方英文原文保留在审计字段；中文、繁体中文和马来文是 StudyMY 本地化内容，不冒充 USM 官方译文。
- 任何官方内部冲突必须写入审计说明，不允许静默推算或覆盖。
- 写库前备份 USM 院校和全部专业；写入、归档和数量校验在事务中完成。

## 发布门禁

- 正式集合 63 项、代码唯一 63 项、slug 唯一 63 项。
- 每项必须具备官方名称、院系、校区、学制、总学费、每学期学费、周期性费用、注册费、入学要求、语言要求、申请材料、intake、职业方向和来源页码。
- `name`、`faculty`、`description`、`requirement.note`、`applicationDocs`、`careers` 和 `specializations` 必须具备四语言结构。
- 公开集合全部 `isPublished=true`、`publicDisplayStatus=ready`、`officialSourceStatus=official-verified`。
- 公开 API 对 USM 本科返回 63 项且无旧记录、无审核记录泄漏。
- 专项测试、全量测试、全量构建和浏览器四语言验收全部通过后才能提交。
