# 院校详情专业列表分页优化

- 日期：2026-06-15
- 状态：已完成
- 范围：院校详情页本科、硕士、博士专业列表

## 需求

专业数量较多时，不再一次性展示全部专业。每个学历层级固定展示 12 个专业，并在列表底部提供上一页、页码、下一页分页控件。

## 实现规则

1. 本科、硕士、博士专业列表均按每页 12 条展示。
2. 页码较多时使用省略号压缩中间页码，始终保留首页、尾页和当前页附近页码。
3. 切换学历层级或院校数据变化时自动回到第 1 页。
4. 翻页后平滑滚动到专业列表顶部，避免用户手动向上寻找列表起点。
5. 沿用现有分页按钮、专业表格、详情弹窗和响应式样式，不调整页面其他设计。

## 验收结果

- 单元测试：`npm test`，136 通过、1 跳过、0 失败。
- Web 构建：`npm --workspace @studymy/web run build` 通过。
- 浏览器验收：
  - USM 硕士专业第一页显示 12 条，共 26 页。
  - 硕士专业切换至第 2 页后，页码和专业内容均正确更新。
  - 从硕士第 2 页切换至博士专业后自动回到第 1 页。
  - USM 博士专业第一页显示 12 条，共 8 页。
  - 浏览器控制台无错误。
