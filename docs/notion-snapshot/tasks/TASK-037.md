## 验收标准
- 用户端所有可见图片优先使用本地项目资源路径，运行时不再依赖 Unsplash 或其他非官方外部图片作为页面展示图。
- 首页、院校列表、院校详情、收藏、对比、推荐弹窗和移动端页面没有破图、空白图、错误图或比例明显异常的图片。
- 图片与静态 HTML 对应页面保持一致；无法完全一致的地方必须写明原因，并采用最接近静态 HTML 的本地资产。
- 图片加载失败时有统一且不突兀的本地 fallback，不出现浏览器破图图标。
- `npm run test`、图片校验脚本、页面截图检查和 `npm run build` 通过。
