- **状态**: 已阻塞

- **任务类型**: 前端
- **负责人**: Codex
- **关联需求**: 产品需求文档

- **实现说明**: 本任务允许修改业务代码和测试代码。基于当前前端页面和数据库导入结果，修复用户端数据展示口径问题，包括院校数量、专业数量、ready 专业数量、学费币种、官方来源、开学时间、语言要求、字段缺失兜底、异常值过滤和列表统计文案。不得大改页面整体布局和视觉风格，只做数据展示正确性和局部显示细节修复。

- **验证结果**: Codex 已完成实现并返回完成状态。
- **阻塞说明**: Review 未通过：本轮 Review 发现 1 个需要修复的问题：学费展示兜底逻辑仍会把后端自动生成的 CNY 年学费当作可信官方学费展示。构建、静态数据校验、现有测试和本地浏览器视觉抽查均通过，但现有测试没有覆盖真实 mapper 输出形态，因此未拦住该问题。

## 验收标准
- 用户端展示的院校数、专业数、ready 专业数、筛选结果数与后端 API 口径一致，并明确公开展示口径。
- 学费、币种、开学时间、语言要求、官方来源状态和审计字段展示不出现 `undefined`、空数组、对象字符串或错误单位。
- 缺失字段有统一兜底文案，例如“以学校官方页面为准”“待官方确认”，且不破坏布局。
- 非专业标题、隐藏未核验或不面向国际学生的记录不会错误进入公开主列表。
- `npm run build`、相关测试和截图复核通过。
