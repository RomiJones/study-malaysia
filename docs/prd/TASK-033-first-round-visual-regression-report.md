## 未修复差异和原因

- 静态 HTML 与 Vue 的数据源不同：静态页使用内置完整数据，Vue 回归脚本使用 mock API 固定少量数据。原因是本任务目标是第一轮前端细节修复，不扩大到真实数据库全量视觉采样；风险是真实数据仍可能触发新长文本或缺字段展示问题；建议后续做真实 API 数据截图回归。
- 静态 HTML 移动端部分入口使用 emoji，Vue 沿用现有文字/符号按钮。原因是当前差异不影响可读性和操作，不属于本轮高价值修复；风险是逐像素验收仍会有差异；建议最终视觉验收前统一图标策略。
- 当前截图脚本检查阻塞级布局和关键元素，不做逐像素相似度断言。原因是历史验收脚本设计如此，本轮不重写视觉基础设施；风险是轻微色差、间距差异需人工抽查；建议后续引入可解释的像素阈值报告。
- 简繁转换仍为项目内手写映射。原因是本轮只处理已发现动态样本，不引入新依赖扩大风险；风险是新增中文词可能继续残留简体；建议后续评估稳定简繁转换库或在数据导入阶段生成繁体字段。
