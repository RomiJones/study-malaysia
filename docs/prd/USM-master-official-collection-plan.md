# USM 国际硕士官方数据采集方案

## 范围

本轮只采集 USM 国际硕士项目，不写数据库。规范范围必须绑定 USM 当前官方研究生目录，以及费用和要求文件各自明确的发布日期或学年。

## 来源优先级

1. USM Postgraduate Programme Directory：规范学位标题、学院、模式和详情入口。
2. 具体项目详情页：学制、模式、校区、入学要求和项目级说明。
3. USM 官方研究生费用文件：国际学生费用币种、集群、计费口径和有效日期。
4. USM 官方研究生申请、英语要求和材料页面。
5. 研究生学院或学院官方页面：补充研究方向和学院级证据。

## 身份规则

- 独立学位标题或独立申请选择计为一个硕士项目。
- Fields of study、research areas、majors、tracks 和 specializations 存入方向字段，不增加项目总数。
- 同名学位在不同学院、校区、模式或合作机构下若官方视为独立申请选择，则保留为独立记录。
- 硕博共用目录必须按官方标题和学位层级拆分，博士不得计入硕士。

## 输出

- 原始来源文件和 SHA-256。
- URL 图与来源角色。
- 硕士规范清单及数量统计。
- 按模式、学院、校区、公开状态、国际资格和费用币种统计。
- 重复、缺失、过期和语义冲突报告。
- 当前官网与明确学年文件差异。
- 五个代表性规范记录。
- 写库前缺口和建议。
