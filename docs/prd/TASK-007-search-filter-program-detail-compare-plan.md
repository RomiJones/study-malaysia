## 4. 静态 HTML 功能分析

### 4.1 状态模型

静态页将搜索、筛选、详情和对比状态集中在全局状态对象 `S` 中：

| 状态 | 字段 | 说明 |
| --- | --- | --- |
| 页面定位 | `page`、`selectedUni`、`selectedProg`、`homePage` | 控制首页、院校详情、专业弹窗和分页 |
| 搜索筛选 | `search`、`qsRankMax`、`tuitionMin`、`tuitionMax`、`categories`、`levels`、`types`、`acceptNoLanguage` | 统一驱动院校列表、专业命中、活跃标签和分页 |
| 收藏对比 | `favorites`、`compareList` | 使用 localStorage 保存未登录状态 |
| 弹窗工具 | `showCalc`、`showRec`、`showAuth`、`authMode`、`mobileMenu` | 与详情弹窗、费用估算、推荐和登录共用弹窗规则 |

相关 localStorage key 包括 `studymy_favorites`、`studymy_compare`、`studymy_profile`、`studymy_material_progress`、`studymy_application_tasks`、`studymy_visa_checklist`、`studymy_user_auth`。

### 4.2 搜索建议

静态页搜索入口位于首页深墨色 Hero 中，核心元素为 `#heroSearch`、`.search-wrap`、`.search-inner`、`.search-suggest` 和 `.search-suggest-item`。

行为规则如下：

- 输入框 `oninput` 立即写入 `S.filters.search`。
- `getSearchSuggestions(q)` 同时搜索院校和专业。
- 院校建议匹配 `name`、`nameEn`、`shortName`、`location`。
- 专业建议只从 `publicDisplayStatus === "ready"` 的专业中生成。
- 专业建议匹配 `name`、`category`、`nameEn`。
- 建议结果按命中分排序、去重，最多展示 8 条。
- 建议项包含类型、院校 id、专业 id、标题、副标题和命中分。
- 点击院校建议进入院校详情。
- 点击专业建议先进入所属院校详情，再自动打开专业详情弹窗。
- Enter 执行搜索并返回首页结果区。
- Escape 关闭建议浮层。
- 点击搜索区外部关闭建议浮层。

后续 Vue 实现不能只做普通文本筛选，必须支持院校、专业、城市混合建议和专业直达弹窗。

### 4.3 筛选组和活跃筛选标签

静态页首页主体使用 `260px 1fr` 布局，左侧为 sticky 筛选栏。筛选组包括：

- 院校类型：公立、私立。
- 学历层次：本科、硕士、博士。
- QS 世界排名：不限、Top 100、Top 200、Top 300、Top 500、Top 800。
- 年学费预算：范围滑杆和快速选择。
- 专业类别：从所有专业类别动态生成。
- 特殊条件：支持免语言申请。

筛选行为如下：

- `filteredUnis()` 统一计算结果列表。
- 关键词匹配院校中文名、英文名、城市、简称和 ready 专业名称/类别/英文名。
- QS、预算、专业类别、学历层次、院校类型、免语言申请可以组合过滤。
- `setFilter`、`toggleCatFilter`、`toggleLevelFilter`、`toggleTypeFilter`、`toggleNoLang` 每次更新后都把 `homePage` 重置为 1。
- `resetFilters()` 重置所有筛选并回到第 1 页。
- `clearFilter(key)` 支持单项移除，并回到第 1 页。
- 左侧筛选栏顶部展示筛选数量和清除全部入口。
- 活跃筛选标签同时出现在筛选栏 `.active-strip` 和右侧结果信息栏 `.active-filter-tags`。
- 没有结果时展示空状态和清除筛选按钮。
- 分页大小为 `PAGE_SIZE = 8`，筛选结果改变后自动纠正页码。

后续实现需要确保 URL、Pinia 状态或服务端查询参数之间有清晰同步策略，避免筛选 UI、结果列表和分页互相漂移。

### 4.4 专业列表和专业详情弹窗

静态页院校详情下的专业列表按本科、硕士、博士分组，公开列表只展示 `publicDisplayStatus === "ready"` 专业。专业列表必须使用静态页 7 列 CSS Grid：

- 专业名称。
- 学院。
- 学制。
- 官方学费。
- 语言要求。
- 开学。
- 详情入口。

专业详情弹窗由 `renderProgModal()` 驱动，桌面端居中，移动端贴底。弹窗字段包括：

- 学历层级、专业类别、学制标签。
- 中文专业名、英文专业名、所属院校。
- 专业简介。
- 同类专业开放状态说明。
- 官方国际学生总学费。
- 开学时间。
- 官方学制。
- 费用备注。
- GPA 要求。
- 雅思要求。
- 托福要求。
- 官方语言要求原文。
- 官方学术要求和备注。
- 中国学生申请备注。
- 官方认证或专业认可。
- 核心课程。
- 职业发展方向。
- 申请所需材料。
- 官方来源状态。
- 核验日期。
- 官方链接。
- 开学备注。
- 官方学费来源。
- 加入申请规划。
- 收藏专业。

后续用户端主流程应以弹窗为专业详情入口，旧系统现有 `/programs/:slug` 独立页最多作为 SEO 或直达辅助，不应替代静态页弹窗体验。

### 4.5 对比功能

静态页对比状态使用 `S.compareList` 和 `studymy_compare` 保存。

行为规则如下：

- 院校卡片对比按钮显示 active 状态。
- 点击已加入项目会移除。
- 点击未加入项目时，如果列表少于 4 所则加入。
- 对比页少于 2 所时展示空状态，引导返回院校库。
- 对比页支持清空全部。
- 对比表横向滚动展示，表头为院校名称和 QS 信息。
- 对比字段包括 QS 排名、院校类型、所在地、建校年份、在校学生、国际生、学费区间、年生活费、最低雅思、免语言申请、专业数量、MQA 认证和查看详情操作。

后续实现应补充“单列移除”能力，满足验收标准中“可添加、移除并展示多个项目差异”的直接操作诉求。静态页当前可通过院校卡片再次点击移除，也可清空全部，但对比表内没有逐列移除按钮。

## 7. 旧系统差距分析

### 7.1 用户端差距

- `apps/web/src/stores/catalog.ts` 已有搜索、分类、层级、QS、预算和免语言筛选，但搜索建议缺失，搜索也没有院校/专业直达弹窗。
- 旧系统筛选是在普通表单和 chip 中完成，不是静态页的 260px sticky 折叠筛选栏。
- 旧系统没有静态页同等的活跃筛选标签、单项移除、筛选组激活圆点和双位置 active tags。
- 旧系统 `toggleCompare` 上限是 3 所，静态页要求最多 4 所。
- `HomePage.vue` 当前是分栏 Hero 与搜索面板，不是静态页深墨色居中 Hero、搜索建议和统计栏组合。
- `UniversityPage.vue` 当前用独立卡片网格展示专业，且专业入口跳转 `/programs/:slug`，不符合静态页专业 7 列 grid 和详情弹窗主流程。
- `ProgramPage.vue` 是独立专业详情页，并且未登录时直接打开登录弹窗；静态页要求院校详情内弹窗展示完整官方字段。
- `ComparePage.vue` 已有对比卡和对比表，但表格字段、视觉、至少 2 所空状态、最多 4 所和逐项移除能力需要按静态页重做。
- `UniversityCard.vue` 已有收藏和对比按钮，但视觉、图像尺寸、QS 浮层、标签、学费显示和 hover 行为与静态页不一致。
