## 保留差异和原因

- 全页面截图中的 sticky 导航在长页移动端截图中仍可能出现在中段位置。这是 Playwright `fullPage` 截图与 sticky 元素组合产生的视觉采样现象，真实浏览器滚动时导航按预期固定在视口顶部；本轮未修改截图脚本，避免改变既有验收口径。
- 静态 HTML 与 Vue 仍使用不同数据源。静态页使用完整内置数据，Vue 全页面回归脚本使用 mock API 固定少量院校和专业；因此文案、费用数字和列表长度不会逐像素一致。
- 右下角浮动工具仍保留在移动端。静态页面也有该工具入口，本轮只降低遮挡感，不隐藏入口或改变交互。
- 当前全页面视觉脚本仍以关键元素存在、横向溢出、文本溢出和弹窗布局为阻塞级判断，不做逐像素相似度断言。
